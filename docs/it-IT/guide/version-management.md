# Gestione delle versioni

Bedrock Nexus tratta ogni configurazione installata come una versione che puoi gestire in modo indipendente.

## Cosa puoi fare

- installare build Release o Preview di Minecraft
- dare alle versioni nomi riconoscibili
- avviare rapidamente una versione selezionata
- rimuovere le versioni che non ti servono più
- aprire le impostazioni specifiche di una versione
- creare un collegamento sul desktop per una versione

## Minecraft Release vs Preview

| Tipo | Ideale per | Note |
| --- | --- | --- |
| Release | Gioco quotidiano stabile | Consigliata per la maggior parte dei giocatori |
| Preview | Provare le modifiche in arrivo | Può danneggiare più spesso mondi, pacchetti o mod |

## L'isolamento spiegato

Quando l'isolamento è abilitato, Bedrock Nexus archivia i dati di gioco gestiti all'interno dello spazio di lavoro dedicato di quella versione, invece di lasciare che tutto condivida la stessa posizione dati predefinita.

L'isolamento è utile quando vuoi:

- set di contenuti diversi per versioni diverse
- test più sicuri per mod o build Preview di Minecraft
- meno rischio che una configurazione influisca su un'altra

## Attività comuni sulle versioni

### Installare una nuova versione

Usa la pagina **Download**, poi torna alla **Home** al termine dell'installazione.

### Rinominare una versione

Usa **Versioni** o la pagina delle impostazioni della versione per dare alla configurazione un nome che ne rifletta lo scopo, come `Release Sopravvivenza` o `Test Preview`.

### Eliminare una versione

Rimuovi le versioni che non ti servono più, specialmente le installazioni di prova di Minecraft Preview che non sono più rilevanti.

::: warning Fai attenzione prima di eliminare
Eliminare una versione può rimuovere l'ambiente gestito di quella configurazione. Prima fai il backup dei mondi importanti.
:::

### Creare un collegamento sul desktop

Bedrock Nexus può creare un collegamento sul desktop per una versione specifica, così puoi avviarla direttamente.

## Strategia consigliata per le versioni

- una versione Release di Minecraft isolata per il gioco normale
- una versione Preview di Minecraft isolata solo quando serve
- una versione di prova temporanea per mod o risoluzione dei problemi
