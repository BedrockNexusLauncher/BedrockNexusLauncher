# Avvio rapido

Se vuoi solo il percorso più breve dal download al gioco, segui prima questa pagina.

## 1. Installa Bedrock Nexus

- Scarica il programma di installazione di Bedrock Nexus da [GitHub Releases](https://github.com/BedrockNexusLauncher/BedrockNexusLauncher/releases).
- Esegui il programma di installazione su Windows.
- Se Windows o il programma di installazione richiede WebView2 o altri componenti necessari, consenti al processo di continuare.

## 2. Assicurati che la configurazione di Microsoft Store sia pronta

- Accedi all'account Microsoft che possiede **Minecraft Bedrock Edition**.
- Installa il gioco da Microsoft Store almeno una volta su questo PC.
- Mantieni disponibili i **Gaming Services**.

::: warning È richiesta una copia legittima
Bedrock Nexus ti aiuta a gestire Minecraft Bedrock (GDK). Non sostituisce la licenza del gioco.
:::

## 3. Apri la pagina Download

- Avvia Bedrock Nexus.
- Apri **Download** dalla barra laterale.
- Scegli se vuoi una build **Release** o una build **Preview**.
- Qui, **Release** e **Preview** indicano rispettivamente la normale build di rilascio di Minecraft e la build Preview.
- Scegli una versione e avvia l'installazione.

## 4. Decidi se usare l'isolamento

L'isolamento conserva i dati di gioco di una versione nel suo spazio di lavoro dedicato, invece di mescolare tutto nella posizione predefinita di AppData.

Usa l'isolamento quando vuoi:

- provare le mod senza influire su un'altra configurazione
- mantenere separati i dati di Minecraft Release e Preview
- mantenere mondi o pacchetti diversi per stili di gioco diversi

## 5. Avvia la versione installata

- Torna alla **Home**.
- Seleziona la versione installata.
- Premi **Avvia**.

Se Bedrock Nexus segnala una dipendenza mancante come GameInput o Gaming Services, segui la richiesta e completa prima l'installazione richiesta.
