# Requisiti e installazione

Questa pagina spiega di cosa ha bisogno Bedrock Nexus prima di poter installare e avviare correttamente le versioni di Minecraft Bedrock (GDK).

## Requisiti di sistema

| Voce | Requisito |
| --- | --- |
| Sistema operativo | Windows 10 o Windows 11 |
| Edizione del gioco | Minecraft Bedrock Edition (GDK) |
| Licenza | Una copia legittima e con licenza associata al tuo account Microsoft |
| Rete | Necessaria per download, metadati delle versioni, test dei mirror e controlli degli aggiornamenti |

## Componenti di Windows richiesti

Bedrock Nexus può guidarti attraverso i componenti mancanti durante il primo avvio o prima dell'installazione.

- **Microsoft Gaming Services**
- **Microsoft GameInput**
- **WebView2 Runtime**

A seconda della tua configurazione di Windows, potresti averne già alcuni installati.

## Prima di installare una versione

Completa prima questo elenco di controllo:

1. Installa Minecraft Bedrock da Microsoft Store almeno una volta.
2. Avvia il gioco una volta se l'installazione dallo Store o i Gaming Services sembrano ancora incompleti.
3. Chiudi il gioco prima di usare Bedrock Nexus per installare o gestire le versioni.

## Installare Bedrock Nexus stesso

### Pagina GitHub Releases

Usa questo metodo se vuoi la pagina di download ufficiale di Bedrock Nexus insieme a note di rilascio e contesto del registro delle modifiche.

1. Apri la pagina [GitHub Releases](https://github.com/BedrockNexusLauncher/BedrockNexusLauncher/releases) di Bedrock Nexus.
2. Scarica il programma di installazione.
3. Eseguilo e completa la procedura guidata di installazione.

## Installare la tua prima versione gestita

1. Apri **Download** in Bedrock Nexus.
2. Scegli **Release** o **Preview** per la build di Minecraft che desideri.
3. Scegli una voce dall'elenco delle versioni.
4. Decidi se abilitare l'isolamento.
5. Avvia l'installazione e attendi il completamento.

## Strategia di installazione consigliata

### Usa una versione Release di Minecraft quando

- vuoi la configurazione quotidiana più stabile
- stai costruendo un mondo a lungo termine
- vuoi meno sorprese con mod e pacchetti

### Usa una versione Preview di Minecraft quando

- vuoi provare le funzionalità in arrivo
- sei a tuo agio con instabilità o interruzioni di compatibilità
- mantieni intenzionalmente i contenuti di Minecraft Preview separati dalla tua configurazione di gioco principale

::: tip Consigliato per la maggior parte dei giocatori
Inizia con una versione **Release** di Minecraft isolata. Aggiungi una versione **Preview** di Minecraft in seguito solo se ti serve davvero.
:::

## Se l'installazione non può continuare

Vai ad [Aggiornamenti e risoluzione dei problemi](./update-troubleshooting) se riscontri:

- Gaming Services mancanti
- GameInput mancante
- stato di proprietà o di installazione dello Store mancante
- problemi di permessi di scrittura
- download non riusciti o problemi con i mirror
