# Início Rápido

Se pretende apenas o caminho mais curto entre a transferência e o jogo, siga primeiro esta página.

## 1. Instalar o Bedrock Nexus

- Transfira o instalador do Bedrock Nexus a partir do [GitHub Releases](https://github.com/BedrockNexusLauncher/BedrockNexusLauncher/releases).
- Execute o instalador no Windows.
- Se o Windows ou o instalador pedir o WebView2 ou outros componentes necessários, permita a continuação do processo.

## 2. Garantir que a configuração da Microsoft Store está pronta

- Inicie sessão na conta Microsoft proprietária do **Minecraft Bedrock Edition**.
- Instale o jogo a partir da Microsoft Store pelo menos uma vez neste PC.
- Mantenha o **Gaming Services** disponível.

::: warning É necessária uma cópia legítima
O Bedrock Nexus ajuda-o a fazer a gestão do Minecraft Bedrock (GDK). Não substitui a licença do jogo.
:::

## 3. Abrir a página de transferências

- Inicie o Bedrock Nexus.
- Abra **Download** na barra lateral.
- Escolha se pretende uma versão **Release** ou uma versão **Preview**.
- Aqui, **Release** e **Preview** significam a versão normal do Minecraft e a versão Preview, respetivamente.
- Escolha uma versão e inicie a instalação.

## 4. Decidir se deve utilizar o isolamento

O isolamento mantém os dados de jogo de uma versão no seu próprio espaço de trabalho, em vez de misturar tudo na localização predefinida da AppData.

Utilize o isolamento quando pretender:

- testar mods sem afetar outra configuração
- manter os dados do Minecraft Release e do Minecraft Preview separados
- manter mundos ou pacotes diferentes para estilos de jogo diferentes

## 5. Iniciar a versão instalada

- Volte a **Home**.
- Selecione a versão instalada.
- Prima **Launch**.

Se o Bedrock Nexus indicar uma dependência em falta, como o GameInput ou o Gaming Services, siga a indicação apresentada e conclua primeiro a instalação necessária.
