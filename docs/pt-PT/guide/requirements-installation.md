# Requisitos e Instalação

Esta página explica aquilo de que o Bedrock Nexus precisa antes de conseguir instalar e iniciar corretamente versões do Minecraft Bedrock (GDK).

## Requisitos do sistema

| Item | Requisito |
| --- | --- |
| Sistema operativo | Windows 10 ou Windows 11 |
| Edição do jogo | Minecraft Bedrock Edition (GDK) |
| Licença | Uma cópia legítima e licenciada associada à sua conta Microsoft |
| Rede | Necessária para transferências, metadados de versões, testes de espelhos e verificações de atualizações |

## Componentes do Windows necessários

O Bedrock Nexus pode orientá-lo relativamente a componentes em falta durante o primeiro arranque ou antes da instalação.

- **Microsoft Gaming Services**
- **Microsoft GameInput**
- **WebView2 Runtime**

Consoante a sua configuração do Windows, poderá já ter alguns deles instalados.

## Antes de instalar uma versão

Preencha primeiro esta lista de verificação:

1. Instale o Minecraft Bedrock a partir da Microsoft Store pelo menos uma vez.
2. Inicie o jogo uma vez se a instalação da Store ou o Gaming Services parecerem ainda incompletos.
3. Feche o jogo antes de utilizar o Bedrock Nexus para instalar ou fazer a gestão de versões.

## Instalar o próprio Bedrock Nexus

### Página do GitHub Releases

Utilize esta opção se pretender a página oficial de transferências do Bedrock Nexus, juntamente com as notas de lançamento e o contexto do registo de alterações.

1. Abra a página do [GitHub Releases](https://github.com/BedrockNexusLauncher/BedrockNexusLauncher/releases) do Bedrock Nexus.
2. Transfira o instalador.
3. Execute-o e conclua o assistente de configuração.

## Instalar a primeira versão gerida

1. Abra **Download** dentro do Bedrock Nexus.
2. Escolha **Release** ou **Preview** para a versão do Minecraft que pretende.
3. Escolha uma entrada de versão.
4. Decida se deve ativar o isolamento.
5. Inicie a instalação e aguarde a conclusão.

## Estratégia de instalação recomendada

### Utilize uma versão Release do Minecraft quando

- pretender a configuração quotidiana mais estável
- estiver a construir um mundo de longo prazo
- pretender menos surpresas com mods e pacotes

### Utilize uma versão Preview do Minecraft quando

- pretender testar funcionalidades futuras
- se sentir confortável com instabilidade ou quebras de compatibilidade
- mantiver intencionalmente os conteúdos do Minecraft Preview separados da sua configuração principal de jogo

::: tip Recomendado para a maioria dos jogadores
Comece com uma versão **Release** do Minecraft isolada. Adicione uma versão **Preview** do Minecraft mais tarde apenas se precisar especificamente dela.
:::

## Se a instalação não puder continuar

Vá para [Atualizações e Resolução de Problemas](./update-troubleshooting) se encontrar:

- Gaming Services em falta
- GameInput em falta
- estado de propriedade ou de instalação da Store em falta
- problemas de permissão de escrita
- transferências falhadas ou problemas com espelhos
