# FAQ, Comunidade e Feedback

## Perguntas frequentes

### Preciso de ter o Minecraft Bedrock?

Sim. O Bedrock Nexus foi concebido para funcionar com uma cópia legítima e licenciada do Minecraft Bedrock Edition (GDK).

### Posso utilizar o Bedrock Nexus no macOS ou Linux?

O destino de utilizador suportado nesta documentação é o **Windows**.

### Devo utilizar Release ou Preview?

Utilize a versão **Release** do Minecraft para jogar normalmente. Escolha a versão **Preview** do Minecraft apenas quando pretender especificamente funcionalidades futuras e se sentir confortável com a instabilidade.

### O isolamento é obrigatório?

Não, mas é fortemente recomendado para testes, versões Preview do Minecraft e configurações com mods.

### Posso gerir mundos e pacotes dentro do launcher?

Sim. O Bedrock Nexus inclui vistas de conteúdos para mundos, pacotes de recursos, pacotes de comportamento, pacotes de skins, capturas de ecrã e servidores.

### Posso instalar mods?

Sim, mas os fluxos de trabalho com mods são uma área avançada. Comece com uma versão isolada limpa e teste gradualmente.

## Comunicar problemas e pedidos de funcionalidades

Utilize o [GitHub Issues](https://github.com/BedrockNexusLauncher/BedrockNexusLauncher/issues) para:

- erros reproduzíveis
- problemas de instalação específicos do Bedrock Nexus
- pedidos de documentação mais clara
- sugestões de funcionalidades com um caso de utilização concreto

## Antes de abrir um problema

- atualizar para a versão mais recente do launcher disponível
- experimentar uma versão isolada limpa
- desativar temporariamente novos mods ou pacotes
- anotar os passos exatos que causaram o problema
