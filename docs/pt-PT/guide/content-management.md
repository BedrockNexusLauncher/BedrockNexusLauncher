# Gestão de Conteúdos

O Bedrock Nexus pode fazer a gestão dos conteúdos que pertencem a uma versão, especialmente quando utiliza configurações isoladas.

## Áreas de conteúdos disponíveis no launcher

- mundos
- pacotes de recursos
- pacotes de comportamento
- pacotes de skins
- capturas de ecrã
- servidores

## Porque é importante a gestão de conteúdos

Para muitos jogadores, o launcher torna-se mais útil depois da instalação das versões, porque ajuda a manter organizados os diferentes ambientes de jogo.

Exemplos:

- uma versão para mundos de sobrevivência vanilla
- uma versão para testar pacotes de recursos
- uma versão Preview do Minecraft com capturas de ecrã e entradas de servidores separadas

## Ações comuns

### Abrir o centro de conteúdos

Abra **Content** na aplicação para ver contagens e atalhos das principais categorias de conteúdos.

### Importar conteúdos

O Bedrock Nexus suporta fluxos de importação, como arrastar e largar, para tipos de conteúdos selecionados.

### Abrir a pasta subjacente

Utilize as ações de abertura de pastas quando precisar de inspeção manual ou de limpeza de ficheiros.

### Manter os conteúdos separados com o isolamento

Quando uma versão está isolada, os seus conteúdos permanecem dentro do espaço de trabalho dessa versão, o que é ideal para testes e organização.

## Hábitos de organização recomendados

- mantenha os pacotes de teste afastados da sua configuração principal de sobrevivência
- faça cópias de segurança dos mundos importantes antes de alterações significativas
- utilize nomes de versão claros, para saber sempre a que configuração pertence cada conteúdo

## Capturas de ecrã e servidores

As capturas de ecrã e as listas de servidores também podem ser mais fáceis de compreender quando cada versão tem um objetivo separado.
