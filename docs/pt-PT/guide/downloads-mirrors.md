# Transferências e Espelhos

O Bedrock Nexus inclui ferramentas para o ajudar a escolher uma fonte de transferência utilizável, a acompanhar o progresso e a utilizar ficheiros de instalação locais quando necessário.

## Para que serve esta área

- explorar as versões instaláveis
- testar ou selecionar os espelhos disponíveis
- acompanhar o progresso ativo de transferências e instalações
- tentar de novo tarefas falhadas com maior facilidade
- importar um pacote de instalação local quando o seu fluxo de trabalho o suportar

## Fluxo de trabalho recomendado

1. Abra **Download**.
2. Escolha a versão Release ou Preview do Minecraft que pretende.
3. Permita que o Bedrock Nexus teste ou utilize o seu espelho preferido.
4. Inicie a tarefa.
5. Abra a vista de tarefas ou do gestor de transferências se pretender um progresso mais detalhado.

## Quando mudar de espelho

Considere mudar de espelho quando:

- as transferências forem invulgarmente lentas
- um espelho falhar repetidamente a ligação
- uma tarefa ficar bloqueada durante demasiado tempo em comparação com outra fonte

## Importação de pacotes locais

Se já tiver um pacote local compatível ou uma fonte de instalação, o Bedrock Nexus pode utilizar fluxos de importação local onde forem suportados.

Isto é útil quando:

- a sua rede for instável
- pretender reutilizar um pacote transferido anteriormente
- precisar de uma fonte de instalação mais previsível

## Se uma tarefa falhar

Verifique o seguinte antes de tentar de novo:

- existe espaço em disco suficiente
- o caminho de destino permite escrita
- os componentes do Windows necessários estão instalados
- o espelho selecionado continua a responder

Continue depois com [Atualizações e Resolução de Problemas](./update-troubleshooting) se a falha persistir.
