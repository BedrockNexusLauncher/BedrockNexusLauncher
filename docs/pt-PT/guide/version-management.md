# Gestão de Versões

O Bedrock Nexus trata cada configuração instalada como uma versão que pode gerir de forma independente.

## O que pode fazer

- instalar versões Release ou Preview do Minecraft
- atribuir nomes reconhecíveis às versões
- iniciar rapidamente uma versão selecionada
- remover versões de que já não precise
- abrir as definições específicas de uma versão
- criar um atalho no ambiente de trabalho para uma versão

## Minecraft Release vs Preview

| Tipo | Ideal para | Notas |
| --- | --- | --- |
| Release | Jogo diário estável | Recomendado para a maioria dos jogadores |
| Preview | Testar alterações futuras | Pode danificar mundos, pacotes ou mods com maior frequência |

## O isolamento explicado

Quando o isolamento está ativo, o Bedrock Nexus guarda os dados de jogo geridos dentro do espaço de trabalho próprio dessa versão, em vez de permitir que tudo partilhe a mesma localização de dados predefinida.

O isolamento é útil quando pretende:

- conjuntos de conteúdos diferentes para versões diferentes
- testes mais seguros para mods ou versões Preview do Minecraft
- menor risco de uma configuração afetar outra

## Tarefas comuns com versões

### Instalar uma nova versão

Utilize a página **Download** e volte a **Home** depois de a instalação terminar.

### Mudar o nome de uma versão

Utilize **Versions** ou a página de definições da versão para atribuir à configuração um nome que reflita o seu objetivo, como `Release Survival` ou `Preview Test`.

### Eliminar uma versão

Remova as versões de que já não precise, especialmente instalações de teste do Minecraft Preview que já não sejam relevantes.

::: warning Tenha cuidado antes de eliminar
Eliminar uma versão pode remover o ambiente gerido dessa configuração. Faça primeiro uma cópia de segurança dos mundos importantes.
:::

### Criar um atalho no ambiente de trabalho

O Bedrock Nexus pode criar um atalho no ambiente de trabalho para uma versão específica, para que a possa iniciar diretamente.

## Estratégia de versões recomendada

- uma versão Release do Minecraft isolada para o jogo normal
- uma versão Preview do Minecraft isolada apenas quando for necessária
- uma versão de teste temporária para mods ou resolução de problemas
