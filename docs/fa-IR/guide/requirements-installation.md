# پیش‌نیازها و نصب

این صفحه توضیح می‌دهد Bedrock Nexus پیش از آنکه بتواند نسخه‌های Minecraft Bedrock (GDK) را به‌درستی نصب و اجرا کند، به چه چیزهایی نیاز دارد.

## نیازمندی‌های سیستم

| مورد | پیش‌نیاز |
| --- | --- |
| سیستم‌عامل | Windows 10 یا Windows 11 |
| ویرایش بازی | Minecraft Bedrock Edition (GDK) |
| لایسنس | یک نسخهٔ قانونی و دارای لایسنس متصل به حساب مایکروسافت شما |
| شبکه | برای دانلودها، فرادادهٔ نسخه‌ها، تست میرورها و بررسی به‌روزرسانی لازم است |

## کامپوننت‌های لازم ویندوز

Bedrock Nexus ممکن است هنگام اولین اجرا یا پیش از نصب، شما را برای کامپوننت‌های گمشده راهنمایی کند.

- **Microsoft Gaming Services**
- **Microsoft GameInput**
- **WebView2 Runtime**

بسته به چیدمان ویندوزتان، ممکن است بعضی از آن‌ها را از قبل نصب داشته باشید.

## پیش از نصب یک نسخه

ابتدا این چک‌لیست را کامل کنید:

1. Minecraft Bedrock را دست‌کم یک بار از Microsoft Store نصب کنید.
2. اگر نصب Store یا Gaming Services هنوز ناقص به نظر می‌رسد، بازی را یک بار اجرا کنید.
3. پیش از استفاده از Bedrock Nexus برای نصب یا مدیریت نسخه‌ها، بازی را ببندید.

## نصب خود Bedrock Nexus

### صفحهٔ GitHub Releases

اگر صفحهٔ رسمی دانلود Bedrock Nexus را همراه با یادداشت‌های انتشار و بافت تغییرات می‌خواهید، از این استفاده کنید.

1. صفحهٔ [GitHub Releases](https://github.com/BedrockNexusLauncher/BedrockNexusLauncher/releases) مربوط به Bedrock Nexus را باز کنید.
2. نصب‌کننده را دانلود کنید.
3. آن را اجرا کنید و ویزارد نصب را به پایان برسانید.

## نصب اولین نسخهٔ مدیریت‌شده

1. در Bedrock Nexus بخش **Download** را باز کنید.
2. برای بیلد ماینکرفتی که می‌خواهید، **Release** یا **Preview** را انتخاب کنید.
3. یک ورودی نسخه را برگزینید.
4. تصمیم بگیرید که ایزوله‌سازی فعال باشد یا نه.
5. نصب را شروع کنید و منتظر تکمیل آن بمانید.

## راهبرد پیشنهادی نصب

### از نسخهٔ Minecraft Release استفاده کنید وقتی

- پایدارترین چیدمان روزمره را می‌خواهید
- در حال ساختن یک جهان بلندمدت هستید
- غافلگیری کمتری با مودها و پک‌ها می‌خواهید

### از نسخهٔ Minecraft Preview استفاده کنید وقتی

- می‌خواهید قابلیت‌های آینده را تست کنید
- با ناپایداری یا شکستن سازگاری مشکلی ندارید
- آگاهانه محتوای Minecraft Preview را جدا از چیدمان اصلی بازی‌تان نگه می‌دارید

::: tip برای بیشتر بازیکنان پیشنهاد می‌شود
با یک نسخهٔ ایزولهٔ **Minecraft Release** شروع کنید. نسخهٔ **Minecraft Preview** را فقط اگر واقعاً لازمش دارید، بعداً اضافه کنید.
:::

## اگر نصب نمی‌تواند ادامه پیدا کند

اگر با این موارد روبه‌رو شدید به [به‌روزرسانی و عیب‌یابی](./update-troubleshooting) بروید:

- Gaming Services گمشده
- GameInput گمشده
- وضعیت مالکیت یا نصب Store گمشده
- مشکلات مجوز نوشتن
- دانلودهای ناموفق یا مشکلات میرور
