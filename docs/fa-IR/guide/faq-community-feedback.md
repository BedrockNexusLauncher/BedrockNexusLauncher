# پرسش‌های متداول، انجمن و بازخورد

## پرسش‌های متداول

### آیا لازم است Minecraft Bedrock را داشته باشم؟

بله. Bedrock Nexus طوری طراحی شده که با یک نسخهٔ قانونی و دارای لایسنس از Minecraft Bedrock Edition (GDK) کار کند.

### آیا می‌توانم از Bedrock Nexus روی macOS یا Linux استفاده کنم؟

هدف کاربری پشتیبانی‌شده در این مستندات **ویندوز** است.

### از Release استفاده کنم یا Preview؟

برای بازی عادی از بیلد **Release** ماینکرفت استفاده کنید. بیلد **Preview** ماینکرفت را فقط وقتی انتخاب کنید که مشخصاً قابلیت‌های آینده را می‌خواهید و با ناپایداری مشکلی ندارید.

### آیا ایزوله‌سازی لازم است؟

نه، اما برای تست، بیلدهای Minecraft Preview و چیدمان‌های موددار به‌شدت پیشنهاد می‌شود.

### آیا می‌توانم جهان‌ها و پک‌ها را داخل لانچر مدیریت کنم؟

بله. Bedrock Nexus نماهای محتوا برای جهان‌ها، پک‌های ریسورس، پک‌های رفتار، پک‌های اسکین، اسکرین‌شات‌ها و سرورها دارد.

### آیا می‌توانم مود نصب کنم؟

بله، اما گردش‌کارهای مود یک بخش پیشرفته‌اند. با یک نسخهٔ ایزولهٔ تمیز شروع کنید و به‌تدریج تست کنید.
