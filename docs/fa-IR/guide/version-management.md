# مدیریت نسخه‌ها

Bedrock Nexus هر چیدمان نصب‌شده را یک نسخه در نظر می‌گیرد که می‌توانید مستقل مدیریت کنید.

## چه کارهایی می‌توانید بکنید

- بیلدهای Minecraft Release یا Preview را نصب کنید
- به نسخه‌ها نام‌های قابل‌شناسایی بدهید
- نسخهٔ انتخاب‌شده را سریع اجرا کنید
- نسخه‌هایی را که دیگر لازم ندارید حذف کنید
- تنظیمات اختصاصی هر نسخه را باز کنید
- برای یک نسخه میانبر دسکتاپ بسازید

## Minecraft Release در برابر Preview

| نوع | مناسب برای | نکات |
| --- | --- | --- |
| Release | بازی روزانهٔ پایدار | برای بیشتر بازیکنان پیشنهاد می‌شود |
| Preview | تست تغییرات آینده | ممکن است بیشتر اوقات جهان‌ها، پک‌ها یا مودها را خراب کند |

## ایزوله‌سازی توضیح داده شد

وقتی ایزوله‌سازی فعال است، Bedrock Nexus داده‌های مدیریت‌شدهٔ بازی را داخل فضای کاری خود آن نسخه نگه می‌دارد، به‌جای اینکه همه‌چیز یک محل دادهٔ پیش‌فرض مشترک داشته باشد.

ایزوله‌سازی مفید است وقتی می‌خواهید:

- برای نسخه‌های مختلف، مجموعه‌محتواهای متفاوت داشته باشید
- برای مودها یا بیلدهای Minecraft Preview تست امن‌تری انجام دهید
- خطر تأثیر یک چیدمان روی چیدمان دیگر کمتر شود

## کارهای رایج نسخه‌ها

### نصب یک نسخهٔ جدید

از صفحهٔ **Download** استفاده کنید و بعد از پایان نصب به **Home** برگردید.

### تغییرنام یک نسخه

از **Versions** یا صفحهٔ تنظیمات نسخه استفاده کنید تا به چیدمان نامی بدهید که هدفش را نشان دهد، مثل `Release Survival` یا `Preview Test`.

### حذف یک نسخه

نسخه‌هایی را که دیگر لازم ندارید حذف کنید، به‌ویژه نصب‌های تست Minecraft Preview که دیگر کاربردی ندارند.

::: warning پیش از حذف مراقب باشید
حذف یک نسخه می‌تواند محیط مدیریت‌شدهٔ آن چیدمان را پاک کند. اول از جهان‌های مهم پشتیبان بگیرید.
:::

### ساخت میانبر دسکتاپ

Bedrock Nexus می‌تواند برای یک نسخهٔ مشخص میانبر دسکتاپ بسازد تا مستقیم اجرایش کنید.

## راهبرد پیشنهادی نسخه‌ها

- یک نسخهٔ ایزولهٔ Minecraft Release برای بازی عادی
- یک نسخهٔ ایزولهٔ Minecraft Preview فقط وقتی لازم است
- یک نسخهٔ تست موقت برای مودها یا عیب‌یابی
